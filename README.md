# Гримуар — Тень Повелителя Демонов

Статический сайт на русском языке для поиска заклинаний и ведения личного гримуара. Работает без сервера приложений, сборки, регистрации и внешних сервисов.

## Возможности

- 330 заклинаний из 30 традиций, ранги 0–5.
- Полные описания из предоставленной книги игрока v0.90 от 25.11.2025, страницы 106–131. Таблица «Дикая магия» представлена отдельно.
- Поиск по названию и тексту эффекта (е/ё равнозначны), фильтры по традиции, рангу и типу, сортировка.
- Выбранные заклинания с теми же полными описаниями.
- Имя и заметки персонажа, автоматическое сохранение в localStorage.
- Экспорт и импорт JSON для резервной копии и переноса между устройствами. Импорт заменяет текущего персонажа после подтверждения.
- Адаптивный интерфейс, управление с клавиатуры, диалоги с закрытием по Escape.

## Открыть локально

Открой `index.html` в браузере. Для стабильного адреса локального сохранения удобнее запустить HTTP-сервер из папки проекта:

```sh
python -m http.server 4173
```

Открой http://localhost:4173. Сохранения привязаны к браузеру и адресу сайта; автоматической синхронизации между устройствами нет. Перед сменой адреса или очисткой браузера экспортируй персонажа.

## GitHub Pages

1. Загрузи файлы проекта в репозиторий GitHub.
2. В настройках репозитория открой **Settings → Pages**.
3. Выбери **Deploy from a branch**, свою ветку (например, `main`) и папку **/ (root)**.
4. Сохрани настройку и дождись публикации. GitHub покажет адрес сайта.

Все пути относительные: сайт работает и в корне домена, и по адресу вида `https://username.github.io/repository/`. Сборка и секреты не нужны. PDF для работы сайта не требуется и в проект не включён.

## Файлы

- `index.html` — структура страницы.
- `style.css` — оформление и мобильные стили.
- `app.js` — поиск, фильтры, гримуар, импорт/экспорт.
- `data/spells.js` — извлечённый каталог.
- `scripts/extract_spells.py` — воспроизводимое извлечение из конкретной версии PDF (Python + pdfplumber).
- `scripts/test-browser.cjs` — проверка основных сценариев в Playwright.

Для повторного извлечения:

```sh
pip install pdfplumber
python scripts/extract_spells.py "path/to/Тень Повелителя Демонов - Книга игрока [v0.90] [25.11.2025].pdf"
```

Для проверки каталога и JavaScript:

```sh
npm run check
```

Для браузерных проверок установи зависимости (`npm install`), браузер (`npx playwright install chromium`), запусти локальный сервер на порту 4173, затем `npm test`. Можно использовать установленный Edge, задав переменную окружения `BROWSER_CHANNEL=msedge`.

## Источник

Неофициальный инструмент по предоставленной пользователем книге. Тексты правил принадлежат их правообладателям. Содержимое PDF используется как данные, а не как инструкции. Каталог извлечён по колонкам, проверен на 330 уникальных записей, по 11 в каждой традиции. Номера страниц соответствуют печатной нумерации книги. Формулировки правил сохранены; сайт не проверяет допустимость выбора для конкретного пути персонажа.

## Применения заклинаний

Выбери Мощь от 0 до 10 над каталогом. Панель показывает число применений **каждого** заклинания соответствующего ранга по таблице на стр. 103 книги. Это отдельные запасы заклинаний, а не общий запас ранга.

У выбранных заклинаний в каталоге, гримуаре и подробном описании есть кнопки «Использовать −1» и «Вернуть +1». Кружки и число показывают остаток. При исчерпании запаса или недостаточной Мощи использование недоступно. «Восстановить все применения» сбрасывает расходы после отдыха (правило на стр. 103: отдых и не менее минуты медитации, учёбы или ритуала).

Изменение Мощи пересчитывает максимум, сохраняя число уже потраченных применений. Удаление и повторное добавление заклинания не восстанавливает запас. Мощь и расходы сохраняются в браузере и входят в экспорт персонажа. Старые файлы без этих полей поддерживаются: Мощь 0, расходы отсутствуют. Особые бонусы путей к числу применений пока не учитываются.

Проверка счётчиков: `node scripts/test-casting.cjs` при запущенном сервере на порту 4173 (те же настройки Playwright, что для остальных браузерных тестов).
